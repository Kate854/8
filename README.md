# Сатурн — прототип 8, Тип 2

Подарок за **каждые полные 1000 ₽** товаров акции. Подарок фиксированный: герметик Vetonit Comfort Sil серый 06 (280 мл). Количество кратное, без ограничения одним подарком.

Публичный адрес: https://kate854.github.io/8/ . Исходники — `main`, публикация — `gh-pages`.

## Запуск

```sh
npm install
npm run dev
```

- `npm test` — 20 тестов логики.
- `npm run build` — проверка TypeScript и автономная сборка.
- `npm run preview` — локальный просмотр production-сборки.
- `prototype.html` — один готовый HTML для скачивания. React, стили, SVG и логика встроены; сервер и интернет для открытия файла не нужны.
- `docs/index.html` — идентичная копия публикации. После изменений пересобрать и обновить обе копии и ветку `gh-pages`.

## Логика

Количество начисленных подарков: `floor(сумма товаров акции / 1000)`.

До следующего: `(количество + 1) × 1000 − сумма`.

Поэтому при точных 1000 ₽ начислен один подарок, а до второго не хватает 1000 ₽. При 2000 ₽ начислены два, до третьего — 1000 ₽. Верхнего лимита подарков нет. Расчёты выполняются в копейках, чтобы 999,99 ₽ не превращались в 1000 ₽.

Динамическая шапка корзины **никогда не зеленеет**, сохраняет оранжевую иконку и кнопку «Добавить товары». После первого подарка предлагает второй, затем третий и так далее.

В поп-апе по макетам пять товаров: 444 / 700 / 578 / 624 / 662 ₽. Изменения — черновик. Подтверждение доступно, когда выбранные товары увеличат число начисленных подарков хотя бы на один. До подтверждения корзина не меняется. Зелёное сообщение о готовности предусмотрено только внутри поп-апа, как во вложении; шапка корзины остаётся нейтральной.

Сценарий из макетов:

1. Изначально 555 ₽ товаров акции: до первого подарка 445 ₽.
2. Добавить клей за 700 ₽ и подтвердить: 1255 ₽ → 1 подарок, до второго 745 ₽.
3. Снова открыть поп-ап и добавить 2 штукатурки по 444 ₽: 2143 ₽ → 2 подарка, до третьего 857 ₽.
4. При дальнейших покупках количество растёт; при уменьшении суммы пересчитывается вниз.

Неакционные товары, услуги и бесплатные подарки в порог не входят. Чекбоксы управляют суммой оформления; право на подарки считается по находящимся в корзине товарам акции, как в предыдущем прототипе.

Подарки одной модели показаны одной строкой с вычисляемым количеством, бесплатно. Удаление корзиной убирает уже начисленные подарки без изменения платной суммы. Новые подарки могут начисляться при следующих порогах. Удалённые можно вернуть кнопкой «Вернуть подарки». При падении суммы количество отменённых подарков ограничивается текущим правом.

## Проверено

20 тестов: границы 999 / 999,99 / 1000 / 1999,99 / 2000 / 3000, большие суммы без верхнего лимита, следующий порог, отсутствие двойных строк, черновики, удаление, неакционные позиции и расчёт в копейках.

В Chromium кликами проверены состояния из макетов, 1/2/3 и больше подарков, 745/857 ₽, нейтральный цвет шапки и неизменная доступность CTA, снижение порогов, удаление/возврат, четыре способа закрытия, фокус, мобильная прокрутка, автономность HTML и отсутствие ошибок JavaScript.

## Дизайн и данные

Интерфейс собран по приложенным изображениям и предыдущему прототипу. Изображения упаковок и знак логотипа — SVG-иллюстрации вместо отдельно не предоставленных фотографий. Скриншоты целиком не используются.

В макетах общий итог не совпадает с ценами отдельных строк. Для корректного динамического поведения используются суммы цен строк. Четвёртый неакционный товар Granit Fix за 967 ₽ взят из финального макета. Услуги, скидка по карте и бонусы вне механики подарка остаются демонстрационными данными макета.
